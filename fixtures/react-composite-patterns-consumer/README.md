# Composite patterns consumer

Synthetic consumer for the shared Collection List, Card Gallery, Design System Gallery structure, and Process Stage Indicator. It uses no application data, routing, permissions, workflow transitions, or business state machine.

The fixture must install an exact qualified `.tgz`, Fluent 9.74.7, and one React/React DOM 19.2.7 instance. It imports shared static styles explicitly and supplies the nonce-aware Fluent renderer for strict-CSP browser qualification.
