首包不包含 Button 全应用替换、表单必填规则、Dialog/Sheet 替换、New Enquiry、Quote、审批、Issue、定价、Builder、身份权限或任何 API/数据库变更。Button/Field/Dialog 已有包级证据，无需为了覆盖组件数量在真实业务里人为增加操作。

| 验证点 | 保持不变/通过条件 |
