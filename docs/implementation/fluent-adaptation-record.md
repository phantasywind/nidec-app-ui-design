## Implementation

The public native Button contract is preserved. `disabled={undefined}` is normalized to false for Fluent's exact optional props. An object ref is forwarded through a callback; callback refs retain identity. The wrapper explicitly renders a button and retains default `type="button"`. No compiler strictness was relaxed and no type assertion hides the production adapter mismatch.

NidecProvider requires an explicit full theme and sets `data-nidec-ui`. Its public type omits the two upstream unstable styling properties. Only the approved Input/Field/Dialog family is re-exported. React, React DOM and Fluent remain external peers; Fluent is pinned to 9.74.7 as both optional peer and development dependency. Token-only consumers do not install React or Fluent.

The React fixture demonstrates official light/dark themes, controlled/error/disabled/read-only fields, ref focus and modal interactions. Its optional response-specific renderer nonce is test infrastructure, not a change to CPQ/EPM security policy or an approved Nidec theme.
