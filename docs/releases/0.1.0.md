# `@phantasywind/nidec-app-ui-design@0.1.0`

Status: QUALIFIED / PUBLICATION APPROVED (2026-10-09); remote publication/readback pending.

Locke approved preparation of the first stable version after reviewing the English catalog and sizing guidance. Final artifact/hash approval, source commit, tag, registry publication and GitHub Release are separate pending steps. No published rc.4 artifact is overwritten.

## Changes since rc.4

- Add the upstream Fluent Dropdown and DropdownProps exports; retain native Select for compatibility. Ordinary choices use Dropdown; searchable choices use Combobox.
- Shared Option preserves Fluent props and behavior while applying token-based green hover/selected treatment, including portals. Forced-color mode remains system-owned.
- Reduce excessive secondary heading/text emphasis; preserve designated primary identities and group labels. SegmentedControl defaults to small; explicit medium remains supported.
- Reorganize the English preview into Forms, Page building blocks, Specialized components and Examples, with 30 routes, real interactions, recommendations, code and responsive layout examples.
- Add component catalog, adoption/replacement guidance, and explicit field-width versus control-size rules. Correct README version guidance.

DatePicker, Editable Grid, Grouped Table, Stage Navigator, BPF and page layouts are retained from rc.4, not newly introduced in this version. The separately recorded table-header color proposal is not implemented. Application logic, routes, permissions, persistence and business transitions remain consumer-owned.

## Adoption after publication

Configure `@phantasywind:registry=https://npm.pkg.github.com` without storing credentials in the repository, then install:

```powershell
npm install --save-exact @phantasywind/nidec-app-ui-design@0.1.0 @fluentui/react-components@9.74.7
# Only when consuming /date-picker:
npm install --save-exact @fluentui/react-datepicker-compat@0.6.39
```

Use an application-qualified exact React/ReactDOM 19.2.x pair; package checks use 19.2.7. Read the version-matched [adoption guide](../consumer-ui-adoption.md) and [component catalog](../component-catalog.md). The archive includes dist and README only; full docs are in the matching Git tag/Release. Inspect typography, compact controls and actual host CSS during upgrade. Set `size="medium"` explicitly where the previous SegmentedControl density is intentional.

Consumers retain their previous exact package/lockfile as the rollback point and own application testing, acceptance and deployment. A stable package label is not Production approval or a 1.0 API stability promise.
