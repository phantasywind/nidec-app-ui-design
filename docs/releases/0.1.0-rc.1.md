## Frozen first-release scope

The release candidate provides framework-neutral light-theme tokens and static composite styles plus a finite React API for forms, overlays, feedback, navigation, menus, tables/data grids, cards, content/status controls and three business-neutral compositions: `CollectionList`, `CardGallery`, and `ProcessStageIndicator`.

Data Table presentation uses the approved Fluent Table family directly; sorting, selection, pagination, virtualization, loading, column meaning and business status mapping remain consumer-owned. Process stage transition rules, permissions, persistence and routing also remain consumer-owned.

No application DTO, API, RBAC rule, route, business state machine, Dark Mode, custom font, icon registry, chart system or file-upload workflow is included.

## Release hardening deltas

- Replace publication-blocked scaffold tokens with 16 ADR-0006 light-theme roles generated into `tokens.css`, `tokens.json`, and the internal Fluent theme palette.
- Keep both static CSS entrypoints explicitly side-effectful while React, React DOM and Fluent remain external peers.
- Reduce the interactive process-stage target to its content and terminate connectors at marker edges; use Fluent transparent-button states so hover paint does not cover the connector.
- Guard actual publication behind exact explicit authorization, a clean worktree and matching immutable tag.
- Add a cold Navigation install/build check for the reported EIDC `@fluentui/react-icons` question. Fluent 9.74.7 currently resolves icons transitively; the shared package will not invent a direct dependency unless isolation reproduces a missing runtime contract.
