## Scope

Since `rc.3`, this version adds the governed DatePicker subpath, Editable Grid and Grouped Table / Grouped Editable Grid patterns. Stage Navigator separates a node's own status from the selected workspace; Business Process Flow allows view-only navigation to reached stages while upcoming stages remain non-interactive. The BPF selection outline follows the arrow with a neutral gap and does not change the authoritative process-state fill. Consumer workflows, APIs, roles, data and transitions remain outside the package.
