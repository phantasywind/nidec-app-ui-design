# `@phantasywind/nidec-app-ui-design@0.1.2`

Status: PREPARED / NOT QUALIFIED / NOT PUBLISHED (2026-10-09).

Prepared by Claude as maintainer (ADR-0007). Accountable owner and authorizer: Locke Yuan. Nothing below is claimed as verified for the candidate archive until the release workflow has qualified it and Locke has authorized the exact version and SHA-256.

Version `0.1.1` was never published: its release run failed before anything was uploaded, because of a defect in the release workflow, and the tag `v0.1.1` was left on the remote. By Locke's decision that tag stays untouched and this version carries the same content under a new version number. See [0.1.1](0.1.1.md). Nothing was ever installable as 0.1.1, so no consumer is affected by the skipped number.

## Change type

Visual refinement relative to `0.1.0`. No export, prop, type, dependency or peer-version change. No business behaviour change.

| Area | Change | Who is affected |
| --- | --- | --- |
| `ApplicationNavigationItem` | A hovered navigation item now has a subtle grey background (`colorSubtleBackgroundHover`) in addition to the brand-coloured label it already had. | Any application showing the application navigation. |
| `EditableGrid` | The divider line before the frozen Actions column (the last header cell and each action cell) is removed. The column still stays visible and opaque at the right edge when the grid scrolls horizontally. | Applications using `EditableGrid` or the grouped editable grid. When the grid is scrolled horizontally, content now passes under the frozen column without a dividing line. |

## What applications should do

- Re-inspect the application navigation hover state and every Editable Grid after upgrading. Both are visible changes; neither changes behaviour, markup or class names.
- Dependencies are unchanged: `@fluentui/react-components@9.74.7`, `@fluentui/react-datepicker-compat@0.6.39` (only for `/date-picker`), and an exact React / React DOM 19.2.x pair. No lockfile change other than this package is needed.
- Applications that overrode these two styles locally, for example to remove the Actions-column divider or to add a hover background, can delete those overrides after checking the result.

## Adoption after publication

Configure `@phantasywind:registry=https://npm.pkg.github.com` without storing credentials in the repository, then install:

```powershell
npm install --save-exact @phantasywind/nidec-app-ui-design@0.1.2 @fluentui/react-components@9.74.7
# Only when consuming /date-picker:
npm install --save-exact @fluentui/react-datepicker-compat@0.6.39
```

Read the version-matched [adoption guide](../consumer-ui-adoption.md) and [component catalog](../component-catalog.md) at the `v0.1.2` tag. The archive includes dist and README only.

Consumers retain their previous exact package and lockfile (`0.1.0`) as the rollback point and own application testing, acceptance and deployment. Publication of this version is not application adoption approval, independent acceptance or Production approval.

## Unchanged and out of scope

- The table-header colour direction (`docs/table-header-visual-direction.md`) is still not implemented.
- Documentation, the Claude Design System build under `design-system/`, and the release workflow are repository changes only and are not part of the package.
