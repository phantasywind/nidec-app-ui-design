## Released scope

This release retains the governed form, overlay, feedback, navigation, menu, Table/DataGrid, card, status and content surfaces from `0.1.0-rc.1`, and adds the qualified mainline contracts developed after that immutable release.

Data Table governance now includes `RecordIdentityCellLayout`, governed record headers and `TableActionIconButton`. A row declares one primary record identity through a semantic Link; selection, ordinary fields, status, metadata and row actions remain separate. Direct row actions use transparent small icon buttons with accessible names and Tooltips; overflow actions may use a three-dot Menu. Columns, data loading, sorting, pagination, virtualization, navigation, authorization and business effects remain consumer-owned.

`CollectionList` remains the compact collection composition and `CardGallery` remains the responsive gallery composition. `StageNavigator` represents user-switchable sibling workspaces and exposes activation. `BusinessProcessFlow` is a read-only arrow lifecycle whose current stage is controlled only by application business state. The ambiguous `ProcessStageIndicator` is retained only as a deprecated compatibility export. See `docs/stage-pattern-selection.md` for the required selection rule.

No application DTO, API, RBAC rule, route, business state machine, Dark Mode, custom font, icon registry, chart system or file-upload workflow is included.

## Known limits

The browser seal retains `axe-color-contrast-incomplete:process-stage-overlap` for process-stage pseudo-element analysis. Independent geometry assertions verify that connectors terminate at marker borders and hover paint does not cover the line.

At 900px and 720px, Fluent `TableCellLayout truncate` can cause axe to return `color-contrast` as incomplete for the deliberately truncated long record-identity Link with message key `bgOverlap`. Pixel hit testing confirmed that visible glyphs remain owned by the Link, and the separate computed-color check remains at or above 4.5:1. The seal permits only this exact fixture target, narrow viewport and message signature, recording `axe-color-contrast-incomplete:truncated-record-identity-at-narrow-viewports`; other unrecognized targets remain blockers.

Some broad demonstration consumers produce Vite's warning for JavaScript chunks above 500 kB. The warning is retained as an application code-splitting observation; no artificial threshold was raised. Package qualification does not establish a universal application bundle budget.

Package qualification does not establish independent application acceptance, Production approval, all-browser WCAG compliance, deployed-host CSP compatibility or business-process correctness. Applications consume only this exact version, preserve their own lockfile and business contracts, and complete their own compatibility, acceptance, deployment and rollback gates.
