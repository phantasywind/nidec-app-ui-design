# Nidec App UI Design

Shared, versioned UI design system for Nidec CPQ and EPM applications.

This private repository is the source of truth for the Nidec Engineering Design System package `@phantasywind/nidec-app-ui-design`. It owns reusable UI foundations and their build, verification, documentation, and release mechanisms. CPQ and EPM retain ownership of application integration and business behavior.
