TableActionIconButton is the transparent 24 by 24 icon-only action for table rows.

Its appearance, size and shape are fixed by the package. Pass the icon, a non-empty accessible label and a Tooltip. Place it in the row's action cell; several or low-frequency commands go into a Menu instead.

The consumer provides the icon, label and handler, and decides which commands exist and who may run them.

- Never replace it with a filled square button or a text button.
