Menu holds low-frequency or secondary commands behind a trigger, built from MenuTrigger, MenuPopover, MenuList, MenuItem and MenuDivider.

Use it for commands, not for choosing a field value; use Dropdown for a field. Put a row's less common commands in a Menu behind a labelled overflow trigger.

The consumer provides the items, handlers, enabled state and permissions.

- Keep the popover opaque and the item order stable.
- Label the trigger when it is icon-only.
