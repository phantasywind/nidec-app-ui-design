MessageBar shows a local status message with a title, body and optional actions (MessageBarTitle, MessageBarBody, MessageBarActions).

Use it for status or errors close to what they affect. An important error must also appear next to the field, not only here. Pair every intent with a word or icon; colour alone is not enough.

The consumer provides the intent, the text and any actions. What counts as a warning, success or error is an application decision.
