WorkspaceSection is the standard white content module for forms, directories, tabs, lists, facts and supporting regions.

It has a title, optional description and actions, and content. Every module is white with one light neutral border, the shared large radius and consistent padding. Keep status, metadata, tabs and local actions in the same section as the content they govern. Use vertical space between peer sections.

Do not wrap sections in another card, add a second border or shadow inside one, or put a grey band behind them. A Card inside a bordered section stays flat. The consumer provides the content.
