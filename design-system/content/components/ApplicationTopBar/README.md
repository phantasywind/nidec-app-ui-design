ApplicationTopBar identifies the current location and holds environment, help, account and sign-out slots.

Keep it white, flat and quieter than the page header. Put the location or breadcrumb first and utilities and the account after it in reading order. Show an environment as explicit text, not colour alone. Do not duplicate page actions or record status here.

`breadcrumb` adds a second row under a light divider, usually a small Breadcrumb whose last item is the current record. With it, the first row can carry just the application name, the environment and the account: show a non-production environment as plain small text, and keep the logo in the navigation brand area, which collapses on narrow screens.

The consumer provides the content and behaviour of every slot, with accessible names on icon-only controls.
