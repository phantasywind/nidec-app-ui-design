Combobox accepts typed text to match options. Use it for searchable or long lists; use Dropdown for a short, fixed list.

Show a magnifier on the left and the arrow on the right. Import `Combobox` and `Option` from the package entry, and use the shared `Option` so option styling reaches the portal.

The consumer provides the option keys and labels, the query, filtering, remote loading, and the selected key. Typing is not selecting: decide what happens to the old selection when the query changes or is cleared. Show a disabled "No matching results" option when nothing matches.

See Dropdown for the option colours and width rules.
